# Horizonte

Aplicación web para seguir mi ruta hacia una maestría en septiembre de 2027:
hitos con fechas, racha diaria de Python, estado de solicitudes y finanzas personales.

Funciona sin conexión y se instala como PWA. Los datos viven solo en el navegador
(`localStorage`), no hay servidor ni cuenta.

## Uso

Abrir la URL en Chrome y elegir "Instalar aplicación".

## Stack

HTML, CSS y JavaScript sin dependencias. Service worker para funcionar sin conexión.
